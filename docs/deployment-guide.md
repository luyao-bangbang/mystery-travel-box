# 百炼平台部署指南

本文档详细说明如何在阿里云百炼平台上部署「盲盒旅行规划师」智能体。

## 第 1 步：注册百炼平台

1. 访问 [阿里云百炼平台](https://bailian.console.aliyun.com/cn-beijing/model/market)
2. 使用阿里云账号登录（如未注册，需先完成阿里云账号注册和实名认证）

## 第 2 步：创建 Managed Agent

1. 进入百炼平台后，在模型广场中选择 **Managed Agent**
2. 点击「创建智能体」
3. 使用默认配置即可启动，后续可调整模型参数
4. 推荐模型：`qwen-max`（效果最佳）或 `qwen-plus`（响应更快）

## 第 3 步：配置 System Prompt

1. 打开 [`src/system-prompt.md`](../src/system-prompt.md)
2. 将其中的完整内容（从"你是「盲盒旅行规划师」"到末尾的所有规则）复制到智能体的 System Prompt 配置区域
3. 保存配置

## 第 4 步：安装飞猪 Skill

在智能体会话窗口中，输入以下命令安装飞猪官方 Skill：

```
npx skills add alibaba-flyai/flyai-skill
```

安装完成后，智能体即可调用飞猪的酒店、机票、景点、度假产品搜索能力。

## 第 5 步：申请并配置飞猪 API Key

1. 访问 [飞猪 FlyAI 开放平台](https://flyai.open.fliggy.com/)
2. 登录后申请 API Key
3. 回到百炼平台，在智能体配置中添加环境变量：
   ```
   FLYAI_API_KEY=你申请到的APIKey
   ```

### API 调用额度说明

| 身份 | 额度 |
|------|------|
| 未注册访客 | 总计 300 次 |
| 注册用户 | 累计 5000 次，用完后每日补充 100 次 |
| 大赛参赛者 | 可加入大赛交流群 @管理员申请更多额度 |

## 第 6 步：测试验证

1. 新建一个会话
2. 输入测试对话：`我想出去旅游，但不知道去哪`
3. 验证以下关键节点：
   - [ ] 画像采集是否正常引导（2-3 轮对话）
   - [ ] 飞猪 Skill 工具是否正常调用并返回数据
   - [ ] 盲盒线索卡是否正确输出（不泄露目的地）
   - [ ] 惊喜值系统是否正常工作
   - [ ] 揭晓后行程是否包含真实数据
   - [ ] 行前锦囊是否完整输出

## 常见问题

**Q: 飞猪 Skill 安装失败？**
A: 确保在智能体会话（而非百炼控制台）中执行安装命令。如果网络超时，重试即可。

**Q: API Key 配置后工具调用仍失败？**
A: 检查环境变量名是否为 `FLYAI_API_KEY`（全大写，下划线分隔）。配置后需要新建会话才能生效。

**Q: 智能体输出了编造的价格数据？**
A: 在 System Prompt 中强调"所有价格必须来自飞猪 Skill 返回的真实数据"。如果工具调用失败，智能体应告知用户而非编造。

**Q: 如何录制 Demo 视频？**
A: 在百炼平台完成一轮完整对话后，使用屏幕录制工具（如 macOS 自带的 Cmd+Shift+5）录制从画像采集到揭晓的完整过程，建议时长 2-3 分钟。

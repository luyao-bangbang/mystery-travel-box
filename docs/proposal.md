# 盲盒旅行规划师

## 项目概述

"盲盒旅行规划师"是一款基于阿里云百炼平台的 AI 旅行智能体，用户只需提供预算、时间和个性偏好，即可获得一份密封的"盲盒行程"——目的地、路线、住宿全部保密，直到出发前一刻才揭晓。它将旅行规划从"信息过载的比价焦虑"变成"充满期待的惊喜体验"。

## 痛点洞察

传统旅行规划流程冗长且充满决策疲劳：选目的地、比价、看攻略、订酒店、排行程，每一步都在消耗用户的时间和精力。与此同时，大量用户存在"想出去走走但不知道去哪"的模糊需求，尤其在年轻群体中，"说走就走"的旅行方式越来越受欢迎。

现有旅行产品的核心问题在于：所有产品都在帮用户做"更理性的选择"，但旅行的本质是体验和情绪价值。用户需要的不是更多选项，而是一个值得信赖的"旅行惊喜"。

## 产品设计

### 核心理念

用"盲盒"机制重新定义旅行决策——从"我来选去哪"变成"AI 帮我挑一个最合适的惊喜"。降低决策成本的同时，把不确定性转化为期待感。

### 用户旅程

整个体验分为五个阶段：

**第一步：画像采集。** 用户通过简短对话回答 4-6 个问题：预算范围（如 3000-5000 元）、可用天数（如 3-5 天）、出行人数与关系（情侣/朋友/独行）、个性标签（从"爱美食""怕冷""社恐""喜欢小众""户外控""文艺范"等标签中选择 3-5 个）。智能体会根据回答追问关键细节，但不超过 3 轮对话。

**第二步：智能体规划。** 系统进入"盲盒密封"状态，界面展示动态封装动画。后台依次执行：目的地匹配（基于偏好 + 季节 + 天气筛选候选地）、性价比分析（查询近期机票和酒店价格洼地）、行程编排（结合当地特色活动与景点生成日程）、风险评估（检查签证政策、安全提醒等）。

**第三步：盲盒交付。** 系统生成一份密封的行程卡片，展示以下线索但不暴露目的地：气候提示（"这几天平均 22°C，记得带薄外套"）、行程标签（"美食""古城""慢节奏"）、飞行时长范围（"飞行 2-3 小时"）。用户可以选择"忍住不看"获得完整惊喜体验，也可以选择"偷看一眼"提前解锁部分信息。

**第四步：揭晓时刻。** 出发前 24 小时（或用户主动触发），行程正式揭晓。配合倒计时动画，依次展示：目的地城市、航班信息、酒店预订、每日行程安排。

**第五步：行前锦囊。** 揭晓后智能体自动输出一份完整的行前准备清单，包括：行李清单（根据目的地天气和活动定制）、当地隐藏玩法推荐、紧急联系方式、旅行预算明细，以及一段可直接分享到社交媒体的"旅行预告"文案。

### 核心功能亮点

**惊喜值系统：** 每位用户初始拥有 100 点惊喜值，每"偷看"一次扣减对应点数。最终揭晓时根据剩余惊喜值生成不同等级的"旅行预言"彩蛋，增加社交传播动力。

**双人/多人盲盒模式：** 情侣或朋友各自回答偏好问题，智能体综合所有人的画像生成"最大公约数"行程。揭晓时可以互相看到对方的偏好答案，增加互动趣味。

**旅行回忆功能：** 旅行结束后，用户可以回来和智能体聊聊旅途感受，智能体会据此优化下次推荐。形成"旅行-回忆-下次盲盒"的闭环。

## 技术架构

### 整体方案

基于阿里云百炼平台的 **Managed Agent** 搭建，安装**飞猪官方 Skill**（`npx skills add alibaba-flyai/flyai-skill`），智能体即可直接调用飞猪的酒店搜索、机票查询、景点推荐、度假产品等真实数据能力。相比自建 API 或模拟数据，这一方案让参赛作品从第一天就能基于真实库存和价格运行，完整度和可信度大幅提升。

### Agent 设计

在百炼平台创建 Managed Agent，通过精心设计的 System Prompt 实现全流程对话引导。关键设计点包括：结构化偏好采集（将用户模糊描述转化为结构化旅行画像）、多步推理链（从偏好到候选地到最优解的逐步收敛）、输出格式控制（确保盲盒线索和最终行程的结构化输出）、惊喜值状态管理（在对话上下文中维护惊喜值计数和偷看记录）。

### 工具调用

智能体通过飞猪 Skill 获得以下真实数据能力：

**机票搜索（Fliggy Flight Search）：** 查询从用户出发城市到各候选目的地的近期机票价格，寻找价格洼地，为性价比分析提供真实数据支撑。

**酒店搜索（Fliggy Hotel Search）：** 在目标城市搜索符合预算和偏好的真实酒店房源，获取价格、评分、位置等信息，直接纳入行程方案。

**景点与门票搜索（Fliggy Attraction Search）：** 根据目的地和偏好标签检索当地景点、门票和特色体验活动，生成每日行程框架。

**度假产品搜索（Fliggy Vacation Search）：** 检索目的地相关的度假套餐和一日游产品，为行程编排提供打包方案参考。

### 数据流

用户输入 → 偏好解析（Agent 多轮对话）→ 结构化画像 → 候选目的地生成（飞猪机票搜索比价 + 天气筛选）→ 目的地优选（飞猪酒店搜索 + 景点搜索）→ 行程编排（飞猪度假产品 + 景点组合）→ 盲盒封装（输出线索卡片）→ 揭晓 & 行前锦囊生成。

## 评审维度分析

### 创新性（40%）

本项目的创新点不在于技术复杂度，而在于对旅行决策范式的重新定义。现有旅行产品都在做"信息呈现→用户选择"，而盲盒旅行规划师做的是"AI 理解→用户信任→惊喜交付"。这是从"工具型产品"到"体验型产品"的跃迁。

在技术层面，通过多 Agent 协作（偏好理解 Agent + 行程规划 Agent + 盲盒封装 Agent）和精心设计的 Prompt 工程，展示大语言模型在个性化推理和创意输出方面的前沿能力。

### 完整度（30%）

核心路径设计清晰且闭环：从偏好采集到盲盒生成再到揭晓交付，每个环节都有明确的输入输出。得益于飞猪 Skill 提供的真实数据能力，作品可以直接基于真实机票价格、酒店房源和景点信息跑通全流程，无需依赖模拟数据，输出结果的真实感和说服力显著优于纯 Prompt 驱动的竞品。

Demo 展示将聚焦于一个真实的端到端场景：用户输入"预算 4000 元、3 天、情侣出行、爱美食怕冷"，智能体调用飞猪 Skill 完成真实的搜索和规划，在 2 分钟内生成盲盒并现场揭晓，展示一份包含真实航班、酒店和景点的完整行程方案。

### 市场前景（30%）

**需求真实：** 飞猪数据显示，"不知道去哪"是用户流失率最高的场景之一。盲盒模式直接降低决策门槛，将犹豫用户转化为下单用户。

**商业闭环清晰：** 盲盒揭晓即完成交易闭环——用户看到的不是攻略，而是已经匹配好价格的机票和酒店方案，一键即可下单。天然适合 OTA 平台的转化场景。

**传播属性强：** "盲盒旅行"自带社交货币属性，揭晓时刻天然适合截图分享到社交媒体，形成自传播效应。惊喜值系统和双人盲盒模式进一步强化了互动传播能力。

## 总结

盲盒旅行规划师用最简单的交互方式解决了最复杂的旅行决策问题。它不只是一个 AI 工具，更是一种全新的旅行方式——让"不知道去哪"不再是出发的障碍，而是惊喜的开始。
